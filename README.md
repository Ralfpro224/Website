# kleine pause.

Eine responsive Website mit sechs Minispielen: Kreiszeichnen, Reaktionstest, Memory, Zahlenraten, Zeitgefühl und Klick-Challenge. Persönliche Rekorde werden lokal im Browser gespeichert.

## Starten

`npm run dev` startet die Website auf Port 3000. Python 3 wird als statischer Webserver verwendet; es gibt keine zu installierenden Abhängigkeiten. Alternativ lassen sich die Dateien auf jedem statischen Webhosting veröffentlichen.

`npm run check` prüft die JavaScript-Syntax. Die Spiele benötigen weder Konten noch API-Schlüssel. Google Fonts ist optional; bei fehlender Verbindung werden Systemschriften verwendet.
